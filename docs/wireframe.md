# Wireframe — Notum Tecnologia (Site Institucional)

> Rascunho preenchido com base no conceito de marca do Manual de Identidade Visual (lupa = certificar/investigar/autenticar; atuação em produtos tecnológicos, assistência técnica e certificados digitais). Trechos marcados `[CONFIRMAR]` são dados factuais que só o cliente pode confirmar (endereço, telefone, preços, autoridades certificadoras parceiras, números reais, depoimentos) — revise antes de rodar `/build-landing`. O restante da copy já está pronto para uso ou ajuste fino.
